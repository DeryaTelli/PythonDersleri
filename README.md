# Diyabet Risk Tahmini Projesi

Bu proje, CDC Diabetes Health Indicators veri seti kullanılarak
diyabet risk tahmini, fairness analizi ve data leakage incelemesi yapmaktadır.

## İçerik
- Logistic Regression
- Random Forest
- SMOTE
- Feature Selection
- Fairness Analysis
- Data Leakage Analysis
- Income Group Analysis
- FNR/FPR Analysis
- Bootstrap Confidence Intervals
